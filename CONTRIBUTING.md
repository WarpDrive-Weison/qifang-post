# Contributing and feedback

Bug reports and reproducible compatibility findings are welcome through GitHub Issues.

Before opening an issue:

1. Confirm the problem on the newest published pre-release.
2. State the app version, operating system, architecture, and affected platform.
3. Distinguish upload, form-ready, submitted, reviewing, and published states.
4. Include minimal reproduction steps and redacted screenshots or logs.
5. Remove passwords, cookies, tokens, QR codes, private media, and personal account data.

This repository distributes binaries, documentation, and the qifang-post skill; it does not contain the application source code. Pull requests may be closed if they cannot be evaluated against that published scope. For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
