# Security policy

## Supported version

Security fixes are considered for the newest published pre-release only. Older QA builds are unsupported.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting or Security Advisory flow for this repository. Do not open a public issue containing exploit details, credentials, cookies, access tokens, private media, QR codes, or account identifiers.

Include the app version, operating system and architecture, affected platform, reproducible steps, expected and observed behavior, and a minimally redacted diagnostic excerpt. Never attach a real account session or private video when a synthetic sample can reproduce the issue.

Publishing-platform login, captcha, identity verification, risk control, account permission, and agreement prompts are expected trust boundaries and must not be bypassed.
