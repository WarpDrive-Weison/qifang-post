# 齐放Post v0.2.120

Mac QA 预发布 · Apple Silicon / arm64 · 2026-10-19

## 修复恢复循环与素材重新校验

同一个文件路径下的视频被替换后，旧任务仍保存原视频指纹。此前重复恢复可能再次复制旧指纹、准备失败，并误提示封面缺失。本版保留具体原因，显示“需重新准备”，提供明确的重新校验入口。

- 工作台新增“重新校验当前视频”；符合条件的未提交任务提供“重新校验视频”。确认当前文件后更新媒体信息和本地口播分析，保留手动文案、话题与封面。
- 校验不创建发布批次，不上传或发布，不复活已停止任务。变更内容需重新准备与确认；原授权指纹不沿用。
- 校验期间取消、提交、切换账号/素材、封面变化或文件再次改写时，不接受过期结果。
- 校验成功或失败都会关闭进度遮罩，避免工作台无法继续操作。

## 同步包含 0.2.119 封面修复

封面保存回执不再被后续只读检查抹掉；仅对明确槽位、比例及居中裁切样式核验实际显示区域。横竖封面分开核验，不扩大图像误差阈值；错误图片、未知裁切及未关闭弹窗不放行。

保留同标题“发布成功”业务核验、人工长文、AI 有限重试、账号隔离和一次性提交保护。发布成功不代表审核通过或公开可见，同名旧作品仍可能匹配。

## 下载与限制

Mac 安装 DMG 或 ZIP，二选一。Windows 推荐使用 Codex 配合技能使用，大语言模型选择 GPT 5.6 sol 以上模型；不提供 Windows EXE。技能同步为 0.2.120，不等同于 Mac 执行代码或测试覆盖。
