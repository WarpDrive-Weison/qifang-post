# 齐放Post v0.2.118

Mac QA 预发布 · Apple Silicon / arm64 · 2026-10-19

## 抖音上传等待修复

修复“AI 智能推荐封面生成中”被误识别成“视频处理中”的问题。此前视频已有可播放的远程预览及完整表单，但可选推荐封面一直生成，使上传检测反复等待。

本版将局部推荐封面生成与视频上传/转码分开识别。仍需独立上传完成证据与连续读回；真实传输、转码、上传失败继续阻止进入后续步骤。未识别的接口 `code=2000` 不作为成功依据，也不触发盲目重传。用户选定封面的上传、保存和核验要求不变。

保留“发布成功”同标题核验、手工长文、AI 有限重试、话题候选选择、账号隔离和一次性提交保护。升级不会主动修改历史任务、登录态或草稿。

## 下载与限制

Mac 安装 DMG 或 ZIP，二选一。Windows 推荐使用 Codex 配合技能使用，大语言模型选择 GPT 5.6 sol 以上模型；不提供 Windows EXE。技能流程版本同步为 0.2.118，不等同于 Mac 执行代码或测试结果。

安装包仍为 ad-hoc 签名、未经 Apple 公证的 QA 预发布。默认 HTTPS 文案中转保留，私有 APP 源码及开发者账号、任务、Cookie、素材和上游 API Key 不公开。
