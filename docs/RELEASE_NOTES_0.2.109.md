# 齐放Post v0.2.109

Mac QA 预发布 · Apple Silicon / arm64

## 本次更新

- **AI 限字与人工编辑分离**：AI 中文标题最多 20 字、正文最多 60 字；手动编辑母版及平台文案不受这两项生成限制。
- 去除输入框、保存接口、数据重开和母版同步中的自动截断。保留手动换行、网址、话题文本与 Unicode 字符；不再仅根据正文长度判定必须重新生成。
- 平台本身的发布上限单独提示。超限时保留全文并要求调整，不静默裁剪后发布；明确清空的平台正文不会重新回填母版。
- **最终发布二次确认可选**（包含 0.2.108 的更新）：默认开启，在设置中关闭并保存后，仅之后创建的新任务在字段校验通过、内容指纹不变时自动提交。旧任务不追溯授权；重新开启撤销未执行的自动授权。
- 登录、验证码、风控、内容校验和一次性提交保护保留。此开关不扩大 Codex 技能或其他工具的授权。

## 下载

- `QifangPost-0.2.109-macOS-QA-arm64.zip`：备用，与 DMG 二选一。

普通用户仅安装 DMG 或 ZIP 中的 APP。Windows 继续暂停公开分发；本仓库不公开私有应用源码。

## 使用提醒与边界

本机验收：691 项单元测试、19 个浏览器 DOM 测试脚本、封面恢复、两种确认模式的四平台窗口回归、真实输入框长文保存/重开及包内媒体测试通过。已核验安装包并完成本机 0.2.108 → 0.2.109 升级，原有草稿和任务数据保留。

- 手动输入不限 AI 的 20/60 字规则，不代表外部平台接受无限长标题或正文。
- 旧版已经截断且未保存在其他地方的文字无法自动恢复，需要重新粘贴或编辑。
- 关闭二次确认后，工作台按钮显示“校验并发布”，新任务可能直接提交，请在启动任务前检查内容。
- ad-hoc 签名、未完成 Apple Developer ID 公证；不代表其他 Mac 已验收。
- 本次不新增真实平台投稿，不宣称公网发布成功或线上 AI 服务持续可用。
- 上传、表单就绪、已提交、审核中与公开发布分开记录；回执不明时不重复提交。

安装与验收范围见 [INSTALL](INSTALL.md) 和 [QA Scope](QA_SCOPE_0.2.109.md)。
