# 齐放Post v0.2.107

公开 QA 预发布 · 2026-09-11 · Apple Silicon / arm64

## 本次更新

- 修复快手封面弹窗存在多个图片控件时，已绑定的上传选择事件仍被全页唯一性判断拒绝的问题。无有效选择事件、标签不匹配或控件被替换等情况仍拒绝盲目上传。
- 加强封面上传标签、预览图片和保存结果的连续校验；补充多个控件、已有封面及错误回执的回归场景。
- 改进抖音封面推荐提示的识别和恢复，保持同一任务、账号及已上传视频，避免把关闭提示当作封面保存成功。
- 指纹确认及提交期间增加工作台尺寸保护，覆盖取消、失败、并发任务和窗口交接；四平台离线确认链中未出现原生 resize 事件。此前用户遇到的窗口放大精确触发源尚未被稳定复现，不能宣称根因已经全部查清。
- 将完整回归检查和版本源码归档纳入安装包构建前置步骤；源码历史保留在维护者本地，不新增公开应用源码。
- 包含默认 HTTPS AI 文案中转配置；上游 Key 不放入客户端配置。与 0.2.103 不同，默认服务不要求用户自行填写 API Key，访问和额度仍受服务端控制。
- **暂停公开分发 Windows 版，并撤下历史 Windows 安装程序。**本次仅提供 Mac 安装包。

## 下载与安装

- `QifangPost-0.2.107-macOS-QA-arm64.dmg`：推荐安装包。
- `QifangPost-0.2.107-macOS-QA-arm64.zip`：备用，与 DMG 二选一。
- `SHA256SUMS-0.2.107.txt`：以上安装包及配套材料的 SHA-256。
- `qifang-post-skill-0.2.103.zip`：未改动、兼容 0.2.107 的可选 Codex 技能；不是 APP 运行依赖。
- `ffmpeg-9.0.1.tar.xz` / `.asc`：FFmpeg 对应源码及上游签名，仅作第三方合规与核验材料，无需安装。

普通用户只需 DMG 或 ZIP。更新时保留应用数据目录，换电脑后需要重新登录各平台。详见 [安装说明](https://github.com/WarpDrive-Weison/qifang-post/blob/main/docs/INSTALL.md)。
