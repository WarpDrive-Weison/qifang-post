# 齐放Post v0.2.112

Mac QA 预发布 · Apple Silicon / arm64 · 2026-10-05

## 本次更新

- **保存失败不丢文案**：手动编辑保留在当前窗口，提供明确的保存状态和重试入口；准备发布前等待保存完成。
- **关闭前保存保护**：检查未保存文案与设置，支持继续编辑或明确放弃；不会因为关闭窗口而自动保存发布策略或 API Key。
- **保护新手写内容**：AI 返回较晚、AI 保存失败、母版同步成功或失败时，不覆盖操作期间新增的手工文案，保留焦点与选区。失败后无需先改一个字就能重试。
- **设置更可靠**：无效 API 基础地址/模型配置整批拒绝，不出现部分设置生效；各服务的未保存配置分别保留，Key 不进入普通设置文件。
- **任务与界面优化**：增加任务搜索、平台筛选及未完成记录提示；改进窄窗口、空状态、通知去重与可关闭提示，保留蓝白金风格。
- **隐私门禁**：运行包检查账号、任务、Cookie、密钥等敏感文件，开发脚本与本机验收数据不进入 APP。

继续保留 AI 中文标题最多 20 字、正文最多 60 字的生成规则；手动文案不受这两项限制。平台自身上限仍单独校验，不静默截断。最终发布二次确认默认开启；登录、验证码、风控、内容指纹和防重复提交保护不变。
